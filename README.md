# RIA Auto Parts Store

A responsive, dependency-light e-commerce storefront created from the RIA Auto Parts requirements and visual direction established in the chat history.

## Included
- Automotive black/red/silver branding
- Responsive home/shop/about/contact sections
- Search
- Vehicle make/model/year selector
- Product categories and filters
- Product cards
- Working cart with quantity controls
- Cart persistence using browser localStorage
- Phone and WhatsApp contact actions
- Mobile responsive layout
- Deployment-ready static files
